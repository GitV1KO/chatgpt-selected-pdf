# ChatGPT 问答 PDF

自选 ChatGPT 网页聊天里的多条问题、回答，按对话顺序导出 A4 PDF。支持 Chrome / Brave 的 Manifest V3；安装使用无需 Node.js、账号或 API Key。

0.1.2 加宽 PDF 两侧留白：保留 10 mm 外页边距，内容区域内侧再留 10 mm 同底色空隙，正文距纸张左右边缘约 20 mm。网页正文保持比例，不重新排版公式和代码。

0.1.1 修复长回答中公式和代码节点过多、重复保存计算样式导致的快照超限。相同样式共享一份，保留原有计算值和渲染效果；已实测可选择并导出此前失败、包含大量公式和代码的长回答。

**以保留网页外观为目标：复制浏览器已计算的样式，在同一标签页渲染冻结内容，调用浏览器原生截图后无损写入 PDF。PDF 正文为图像，不能直接选择或搜索文字，链接也不能点击。** 标题、公式、代码颜色、表格、图片保留网页的渲染外观；按 A4 分页并加页边距，消息间留间隔，不包含聊天侧边栏和输入框。并不保证所有网页组件都能复现；检测到布局不一致会停止并提示。

## 使用

下载 [0.1.2 安装包](dist/chatgpt-selected-pdf-0.1.2.zip)，或获取本仓库源码。

1. 打开 `brave://extensions` 或 `chrome://extensions`，开启开发者模式，点击「加载未打包的扩展程序」。
2. 选择本项目的 **extension** 文件夹（里面直接有 `manifest.json`）。安装包 ZIP 需要先解压，再选择直接包含 manifest 的目录。
3. 打开任意 ChatGPT 聊天，从浏览器扩展菜单点击 **ChatGPT 问答 PDF**。也可用 `Alt + Shift + P`（Mac 为 `Option + Shift + P`）；快捷键有冲突时可在扩展快捷键设置里修改。
4. 独立勾选问题和回答；「整组」选择该组当前已加载的问答。可搜索、定位、清空或「只看已选」核对。向上滚动加载旧消息后可继续勾选。
5. 点击「保存 PDF」。保持窗口及标签页在前台，等待浏览器下载。导出中可按 Esc 或点击停止。截图预览暂时覆盖网页，完成或失败后自动移除。

更新源码后，在扩展管理页重新加载扩展，再刷新 ChatGPT 页面。加载目录请长期保留，浏览器会持续使用此目录。

**勾选时保存外观快照。** 后续滚动卸载原文不会使已选消息消失。编辑回答、切换回答分支、调整主题或代码横向滚动后，需要取消并重选，才会更新快照。刷新网页、关闭标签页或切换聊天会清空选择。

## 外观与长聊天

- 使用页面当前字体、字号、主题、正文宽度及横向滚动位置。横向被滚动容器遮住的代码/表格仍按当时可见范围导出；需要其它部分时先在网页中滚动或启用网页提供的换行，再重选。
- 长回答按视口分片截图，不创建无限高画布；A4 边界尽量避开文字行、表格行和可容纳的图形。超高图形仍需要跨页。
- 网页代码区吸顶工具栏在 PDF 中按正文位置出现一次，不保持滚动时的吸顶行为；表格采用测量后的列宽，避免重新布局改变换行。
- 只处理网页已经挂载过、且你实际选中的消息。没有调用内部聊天接口或后台下载完整会话；历史没有加载时请先手动滚动。
- 已观察 DOM 顺序与明确的回合序号用于排序。跨完全不重叠的虚拟窗口、且没有可靠序号时，会禁用导出并要求连续滚动建立重叠，避免静默乱序。
- 嵌入窗口、音视频、受跨域保护的 canvas、过大消息暂不支持。仍在生成的消息需等生成完；未加载图片会短暂等待，仍未加载则提示。原网页已经破损的图片按其破图外观保留。
- 外部图片在导出时仍需浏览器能加载原资源；过期链接或重新加载失败会提示。快照不是外部图片资源的永久离线归档。
- 网页 DOM 并非稳定公开接口。ChatGPT 更改结构后可能需要适配，无法承诺所有账号实验版、Canvas 页面或未来布局都兼容。
- 单次最多 200 页、压缩图像总量 256 MB；超出请分批导出。极长代码/富文本快照也受内存限制。

## 权限与隐私

仅申请 `activeTab` 和 `scripting`，不申请所有站点、cookies、tabs、storage、downloads 或 debugger 权限。没有静态站点访问授权；每个新标签页首次使用时需点击浏览器工具栏的扩展入口，授予该页临时访问。

扩展入口只接受 `https://chatgpt.com/`、`https://chat.openai.com/`。后台每次截图前后都核对标签页、窗口和 URL；切换标签页、窗口、会话、缩放或改变窗口尺寸会中止导出。截图会话有时效。

选择、聊天文字、样式、截图和 PDF 都在本机内存处理，不读 Cookie、Token、站点存储或 ChatGPT 私有接口；不上传内容，无遥测、第三方 PDF 库或远程代码。重放图片和 CSS 图片时，浏览器可能重新加载网页已有资源。PDF 通过本地 Blob 下载链接交给浏览器保存。

## 验证

`docs/TESTING.md` 区分独立浏览器模拟页面的集成测试与用户登录页面的真实测试。自动测试用临时配置加载原始 Manifest，通过真实浏览器 action 授予 activeTab，并调用真正的 `captureVisibleTab`、下载 PDF、解析和渲染检查；没有伪造截图 API，也没有扩大测试扩展权限。

```sh
npm install
npm run check
npm test
npm run package
```

开发检查需要支持 ES Modules 的现代 Node.js 和 npm，打包还需要 `python3`。浏览器测试需要支持加载未打包扩展和 `Extensions.triggerAction` 的 Chromium/Brave；已验证环境为 macOS、Brave 和 Playwright 1.64.1。可用 `CSPDF_BROWSER_EXECUTABLE` 指定浏览器，用 `CSPDF_PLAYWRIGHT_MODULE` 指定已安装的 Playwright 模块；没有系统浏览器时，需先安装 Playwright Chromium：`npx playwright install chromium`。

PDF 检查需要 Python 3 的 `pypdf`、`Pillow`，以及 PATH 中的 Poppler `pdftoppm`；可用 `CSPDF_PYTHON` 指定 Python。集成测试使用独立临时浏览器配置，结果写入忽略版本控制的 `tests/results/`。安装扩展本身不需要这些开发依赖。

源码入口：`extension/content.js` 负责识别与选择，`snapshot.js` 冻结外观，`export.js` 渲染与截图拼页，`pdf.js` 写入无损图像 PDF，`background.js` 管理临时授权与截图检查。架构说明见 `docs/ARCHITECTURE.md`。
